# Jatin Kumar Singh — Personal Portfolio

A responsive personal portfolio website with a **Matte Black + Crimson Red** theme.

## Files

- `index.html` — page structure and content
- `style.css` — styling, theme colors, responsive layouts, and animations
- `script.js` — mobile navigation, current year, and reveal-on-scroll effects
- `README.md` — project notes and setup instructions

## Run locally

1. Keep all four files in the same folder.
2. Open `index.html` in a modern web browser.

No build step or external libraries are required.
